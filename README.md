# MiniGPT Knowledge Assistant

Building a GPT-style Large Language Model from scratch
and extending it into a RAG-based knowledge assistant.

## Learning Goals

- Tokenization
- Embeddings
- Self-supervised learning
- Self-attention
- Transformers
- LLM pretraining
- Few-shot prompting
- Fine-tuning
- Vector embeddings
- Vector databases
- Retrieval-Augmented Generation (RAG)
